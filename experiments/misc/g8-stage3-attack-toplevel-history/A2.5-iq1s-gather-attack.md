## b. plan（真-fixable · byte-exact 优先 · structural 归约方案改写）

**杠杆 = deferred-scale-reduction（纯发射重排 · 与 index/gather 正交）**：
1. 循环前声明 `int32_t partsum[8]; int32_t lsArr[8];`（i32 8-lane scratch）。
2. 循环内：**去掉** per-sub-block `vmv.x.s`（`int lsum=vmv.x.s(lacc); sumi+=ls*lsum;`）；
   改为 `vse32_v_i32m1(&partsum[ib], lacc, 1)`（存归约 lane-0，**无 vmv.x.s**）+ `lsArr[ib]=(int32_t)ls`。
   delta 路径（sumi1，用标量 bsums、**无 vmv.x.s**）**不动**。
3. 循环后：`vle32_v_i32m2(partsum,8)` + `vle32_v_i32m2(lsArr,8)` → `vmul_vv_i32m2`（8-lane ls 一次施加）
   → `vredsum_vs_i32m2_i32m1`（seed 0）→ **单 `vmv.x.s`** → `sumi`。

**LMUL 选 m2**：VLEN128 e32m2 VLMAX=8（vl=8 满）；VLEN256 e32m2 VLMAX=16（vl=8 仍满）→ 双 VLEN 恒等。
**byte-exact 论证**：`sumi = Σ_ib ls[ib]*partsum[ib]`，整数加 associative+commutative；
每 lane 积 |ls·d| ≤ 15·(32·127)=60960，Σ8 ≤ 487680 < 2^31 → 无溢出 → vredsum 任意序 == baseline 左结合标量序 → **逐位恒等**。
预期 `vmv.x.s` 10 → ~2（复刻 opp）。
